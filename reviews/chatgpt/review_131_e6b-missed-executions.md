# Review 131 — E6b missed executions in scorecards

**Reviewed:** `story/e6-s2-missed-execution` at **65e29fcf**, Response 218, Response 215, E6b story, S1 pending edit 10, E8 timing and E4c/E4d refusal contracts. **Second reviewer:** ChatGPT, quality rule 9. **Overall: PARTIAL — accept the shared counter, but one attribution/denominator disclosure should be pinned before binding comparisons.** Evidence labels follow AGENTS.md. This is story text, not a code test. No real orders.

## 1. Denominator and gate refusals — PARTIAL (strong evidence for existing outcome classes; reasoning only for scope)

**ACCEPT** defining an *execution opportunity* as an order that actually reaches the fill step, including `opened`, `not_opened` and immediately unwound partial fills. C2/C3/timing/blocked-book `refused` events are **not execution failures**; mixing them into fill rate would make a risk-conscious strategy appear illiquid. Run-level missed decisions are a different operations problem and correctly stay in S6 `missed_runs`.

**CHANGE the reporting interpretation:** gate refusals must remain visible **by strategy and book, with reason and count**, adjacent to execution opportunities; a book repeatedly denied by `margin_room` or the ₹10,000 trade-loss cap may show 100% fill rate on the few orders it sends while achieving few original decisions. The story already says “gate refusals beside” but needs the strategy-level reason breakdown tested, not just one total. **Example:** 100 chosen decisions, 80 C2 refusals, 20 reach fill, all 20 open. Execution fill rate is correctly **20/20 = 100%**; original-decision-to-open rate is **20/100 = 20%**. Display both counts, not necessarily a new computed KPI. The first is liquidity/execution quality; the second is feasibility/capacity. Never claim a 100% fill rate means 100% of signals could be traded.

## 2. Partial fills — ACCEPT (strong evidence)

A partial entry that is immediately unwound never becomes an opened position, so it counts as an execution miss. But it **does** create actual paper cash flows: spreads, C1 brokerage and any legging loss. Its net must enter net per opportunity, not be assigned zero. **Worked example:** nine successful closed positions net +₹900 each, one unwound entry −₹250, and no opens pending: filled-only average = **₹900**, net per opportunity = `(9×900−250)/10 = ₹785`. Counting the unwind as both “not filled” and a −₹250 cash result is not double counting: one is an execution outcome, the other money.

## 3. Open trades — PARTIAL (strong evidence for selection bias; reasoning only for best display)

Excluding unresolved P&L rather than calling it zero is correct. But closed-only trades are a selected subset: a fast stop-loss can close in two sessions while a profitable time-exit remains open for 21 days, or vice versa. **Small disclosure:** report `open_count` plus **oldest open age in sessions** and mark both averages `closed-only / provisional while open>0`. Do not invent unrealised P&L in a closed-trade statistic. When the last open closes, recompute from the same immutable events; never backdate the result. This is reporting, not a new gate.

## 4. Sections and S1 — PARTIAL (strong evidence for board structure; reasoning only for segmentation)

A book-level and per-strategy execution block is enough for the **whole-account descriptive** view, but not enough if an S1 head-to-head or version-segment claim uses only a later subperiod while the displayed fill rate pools earlier pilot/other versions. **Before binding S1 comparison**, show the number of fill-step opportunities and misses **on that exact claim's eligible dates/version** (at least as a short adjacent disclosure), or clearly mark the overall block “all dates, not the claim cohort.” Do not invent a new per-section execution engine now; a simple cohort filter in the existing pure counter is sufficient if the claim actually uses these figures. Example: pilot 20/20 fills, new version 2/10 fills; overall 22/30=73.3% hides a **20%** current-version fill rate. This can mislead a version promotion decision. Since E6b expressly does **not** change S1 verdicts, this is a condition on presentation before the metrics are used for promotion, not a new statistical gate.

## 5. Missing owner-facing number — PARTIAL (strong evidence on arithmetic; reasoning only for scope)

The main missing distinction is **decision feasibility versus execution feasibility**. Keep a visible chain: `chosen decisions → gate refused → reached fill → opened / missed / pending → closed / still open`, per strategy and book. This can be built from the existing event/decision counters; do not count a gate refusal as an execution miss. For E4d, display fixed priority and `size_shared_in_book` by strategy. For E8, distinguish owner-away/price-moved/no-quote, which have different remedies. For closed-only net per opportunity, print its denominator explicitly: `opportunities − open` (excluding pending), with unwinds counted as realised negative nets. Unknown reasons go to `other`, never vanish.

## Financial-role check and final decision

**Mathematician/statistician/quant modeller:** separate conditional fill rate, decision feasibility and open-trade censoring; do not infer skill from the filled subset. **F&O/options/volatility trader:** missing hedge liquidity and price moves affect actual opportunity conversion. **Risk/portfolio/head of desk:** refusing an oversized trade is correct, but persistent refusals reduce the book's achievable edge. **Execution/microstructure:** displayed size and limit prices constrain fills, not original signals. **Market/macro/flows/equity research/investment banking:** event days can concentrate no-quotes and price-moved misses. **Regulation:** paper only. **Behavioural:** do not promote a strategy based only on a lucky filled subset. **Tax/cost accounting:** partial unwinds incur actual C1 charges; no fill incurs none. **Data engineer/red team:** plant a strategy with 80 C2 refusals, a partial unwind and an open trade, and verify both denominators.

**Final verdict: PARTIAL — story text suitable for implementation.** The shared counter and all nine criteria are directionally sound. Require explicit cohort/denominator labelling and strategy-level gate-refusal counts before any owner-facing promotion comparison. No new fill logic, pause rule or scoring framework is justified.
