HOW TO RUN

1. Install Python from python.org (on Windows tick "Add Python to PATH").

2. Double-click nse_raw_download.py
   When it asks "Which folder?", just press Enter.
   The files download into a folder called "raw", inside this same folder.
   (About 30 minutes. If it stops, double-click again: it carries on where it stopped.)

3. Open drive.google.com in your browser, open your fno-research folder,
   and drag the "raw" folder into it. Google Drive uploads it.

That's all. You do not need any Google Drive program on your computer.

If it says "cannot check secure websites" (Mac): open Finder > Applications > Python 3.x,
double-click "Install Certificates.command", then run the script again.
