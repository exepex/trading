## 2. How we work (unchanged rules)

- **Lanes** (`CLAUDE.md` "Branch" and `docs/JUDGE.md`):
  - Lane 1 needs a judge's PASS before main. Money pieces and hard lines get two judges. At most 2 rounds; after
    that the owner decides.
  - Lane 2 needs the orchestrator's check.
  - Lane 3 needs no judge: logs, judge files and register rows.
- **Text-only changes** (every file `.md`) skip the full suite. Run the doc-reading tests:
  `python -m pytest -q -n auto $(grep -rlE "docs/|\.md['\"]" tests --include=*.py)`, plus the record scan and
  `tools/check_numbers.py` on main. The lane is unchanged.
- **Builders never merge;** the orchestrator merges. Tell the builder "I'm merging, don't merge" first.
- **Merge procedure,** in a scratch worktree on detached `origin/main`:
  1. `git merge --no-ff <judged SHA>`. Resolve doc conflicts by keeping both sides; resolve a .py conflict only as
     the judge said.
  2. Run `ruff check fno tests tools`, `ruff format --check fno tests tools`, `python tools/check_imports.py` and
     `python tools/check_records.py`.
  3. Run the full suite:
     `GITHUB_ACTIONS=true GITHUB_RUN_ID=1 GITHUB_SERVER_URL=https://github.com GITHUB_REPOSITORY=exepex/trading env -u FNO_SLACK_BOT_TOKEN PYTHONDONTWRITEBYTECODE=1 python -m pytest -q -p no:cacheprovider -n auto`
     (about 8 minutes, about 15,100 tests).
  4. `git pull --no-rebase origin main`. If any non-.md file came in, run the full suite again.
  5. `python tools/check_numbers.py`.
  6. `git push origin HEAD:main`, retried on a race.
  7. Batch several judged items into one run where possible.
- **Always:**
  - `env -u FNO_SLACK_BOT_TOKEN` for git;
  - `git config core.hooksPath .githooks`;
  - never `--no-verify`;
  - no model names in commits;
  - the commit trailer named in the session's own instructions.
- **No merges 14:00-16:15 IST on sessions** (the live 3 pm parts and the desk).
- **Never create, change or delete scheduled routines.** The owner does that.
- **No real Drive write** without the orchestrator's explicit go. Drive is write-once.
- **Questions to the owner:** simple words, examples, selectable options, tables. Mark evidence as strong, some, or
  reasoning only.
