## Gaps to fix (rehearsal: REH1g, lane 1, judges B and E)

  `source.checksums(folder)`. The real record store, `DriveOnlyQuoteStore`, has no listing, so both parts and the
  15:15 snapshot fail. REH1b's tests used a fake that can list. Fix: list through to the repository's sidecars, and
  test the real composition, not a fake. Strong evidence: a read-only replay of `build_quote_recorder(cfg)` and
  `build_nse_quote_recorder(cfg)` under the mode raises the same error.
- **G2. Librarian and cue manifests are invisible.** `rehearsal/visibility.py` shows a Drive file only when it has an
  O9 receipt. The A9 datasets and the global cues keep their SHA-256 rows in `research/data/manifests/*.csv`. Fix
  (orchestrator, design a): a manifest row is visible as of the git commit that added it. Test with the 16 Oct
  index-close case, plus a no-look-ahead plant.
- **G3. preopen record's waits run at real speed.** They must use the skipping waiter.
- **G4. KOSPI's -5 s window.** The rehearsal reads drift a few seconds from the day's reads. To decide: should a
  rehearsal read use the day's recorded read time?
- **G5. `lab release-check` says "unreachable" in a rehearsal.** It should say NOT_RECORDED. To check with its builder.
- **G6 (follow-up, agreed). Name every dropped path in the run's output**, and install the HTTP guard in the

## Real-day risks found (O1, before Monday 26 Oct 14:05 IST; lane 1)

- **R1. The indices part can lose the day before its window.** It starts "after nifty". If the nifty part dies early
  (here at 14:38), the indices run at once, read "too early" (more than 20 minutes before 15:01) and record nothing.
  The run does not start them again, and the alert wrongly says "canonical none". (Corrected after the first push:
  no "none" marker is written; "too early" skips `close_day`.) Fix: the indices wait for their own window and record
  what they see. Test: a crashed nifty part at 14:38.
- **R2. One unexpected exception ends the whole daily run.** `DailyRun._guarded` catches only `CommitFailed` and
  `GitFailed`. Any other error in a desk step stops the run with no card. Fix: record the step as failed (exception
  type and a one-line reason, plus an alert), go on with the steps that do not depend on it, and refuse those that
  do, per E3's rules. Test: a planted NotImplementedError in the snapshot step.
